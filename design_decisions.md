# Data Schema
CSV storage is used instead of a relational database.

| Column | Type | Range/Meaning |
|---|---|---|
| attendance | integer | 0–100 |
| study_hours | float | 0–24 |
| assignment_completion | integer | 0–100 |
| internal_marks | integer | 0–100 |
| previous_gpa | float | 0–10 |
| sleep_hours | float | 0–24 |
| backlogs | integer | 0–20 |
| risk_level | string | Low / Medium / High |
