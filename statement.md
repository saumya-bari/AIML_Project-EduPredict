# Project Statement

## Problem Statement
Academic performance is influenced by multiple indicators including attendance, study time, assignment completion, internal marks, previous GPA, sleep duration, and backlogs. EduPredict combines these indicators to estimate an academic risk category.

## Scope
EduPredict is a command-line educational AI/ML prototype that predicts Low, Medium, or High academic risk and provides rule-based recommendations.

## Target Users
- Students
- Faculty mentors
- Academic coordinators
- AI/ML learners

## High-Level Features
1. Dataset generation
2. Data validation
3. Random Forest training
4. Risk prediction
5. Confidence reporting
6. Recommendation engine
7. Dataset analytics
8. Automated testing
9. CLI complete-demo execution

The dataset is synthetic and the system is not intended to make official academic decisions.
